## 主要变更

- **自有仓库也纳入提醒**：新增 `issueScope` 与 `prScope`。打开「自动覆盖我名下的所有仓库」后，Issue 流按 `user:@me` 与 `orgs` 覆盖自有仓库和组织；打开「自动覆盖我名下仓库的新 PR」后，PR 流把别人直接在我仓库开的 PR 也报上来，不再依赖「指定评审人」或「@ 我」。默认仍是只查维护仓库与待我评审，升级不改变现有行为；自有 PR 是否需要核心评审，由核心的 `review.repoPr` 决定（[dsh-my-superagent#2](https://github.com/xbzbing/dsh-my-superagent/issues/2)）。
- **自己提的 PR 也会上报**：`author:@me` 的 open PR 以 `github.pr.opened` 交给核心，由 `review.selfPr` 决定要不要评审；插件只上报事实，不自行打扰。
- **配置页更顺手**：两个「自动覆盖」开关改用 DSH 原生 Switch，与设置页其他开关一致；同时修复热重载后旧样式残留导致的标题过大、开关错位。
- **内部**：client 半新增 `@deepseek-ai/dsh-client-ui-primitives` 注入；单测增至 109 条，覆盖范围解析、搜索语句、跨来源去重与自提 PR 过滤。

## English

- **Your own repositories are covered too**: new `issueScope` and `prScope` settings. Turn on “automatically cover all repositories I own” and the issue stream queries `user:@me` plus each entry in `orgs`; turn on “automatically cover new PRs in my repositories” and the PR stream also reports PRs opened directly in your repositories by others, without needing a review request or an @mention. Defaults are unchanged (`repos` / `review`), so upgrading does not alter current behaviour; whether an owned-repo PR gets reviewed is still decided by the core's `review.repoPr` ([dsh-my-superagent#2](https://github.com/xbzbing/dsh-my-superagent/issues/2)).
- **Your own PRs are reported**: open PRs matching `author:@me` are reported as `github.pr.opened` and the core decides via `review.selfPr`; the plugin only reports facts and never nudges you itself.
- **Better settings page**: the two “automatically cover” toggles now use the DSH Switch, matching the rest of Settings; stale injected CSS after hot reload no longer leaves an oversized title or a misaligned switch.
- **Internal**: the client half now injects `@deepseek-ai/dsh-client-ui-primitives`; the suite grew to 109 tests covering scope parsing, search queries, cross-source deduplication and self-PR filtering.

## Install

```bash
# Stable (npm)
dsh plugin --profile web add dsh-github-message@0.1.1

# The same version as a GitHub Release asset
dsh plugin --profile web add https://github.com/xbzbing/dsh-github-message/releases/download/v0.1.1/dsh-github-message-0.1.1.tgz
```

After installing, open **Settings → Plugins → GitHub Messages** and enable the two “automatically cover” toggles as needed; the organization list appears once either toggle is on and takes effect on the next poll after saving.
