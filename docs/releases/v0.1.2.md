## 主要变更

- **操作提示可关闭，成功提示 5 秒后自动消失**：「统计已重置」「已触发一次检查」「已保存轮询配置」这类成功提示现在带 `×`，点一下立即收起，不点也会在 5 秒后自动消失，不再一直占着面板顶部；失败提示（`操作失败：…`、仓库名/组织名/检查周期校验不通过）保持常驻，读完后手动关闭。
- **内部**：提示生命周期抽到 `src/client/notice.ts`；每次提示带自增 id，同一句文案连续出现也会重新计时；单测增至 111 条。

## 安装

```bash
# 正式版（npm）
dsh plugin --profile web add dsh-github-message@0.1.2

# 同一版本的 GitHub Release 附件
dsh plugin --profile web add https://github.com/xbzbing/dsh-github-message/releases/download/v0.1.2/dsh-github-message-0.1.2.tgz
```

## 验证

- `npm run check` 全绿：typecheck + 111 单测 + host/client 构建
- 新增 `test/notice.test.ts`：覆盖 5 秒边界（到期前 1 毫秒、到期、超时）与失败提示不自动消失；把 error 也设上 `expiresAt` 或去掉 `max(0, …)` 会转红

## English

- **Notices are dismissible; success notices clear after 5 seconds**: success messages such as “Stats reset”, “A check was triggered” and “Polling settings saved” now carry a `×` and disappear on their own after 5 seconds instead of sitting at the top of the panel; failure messages (`Action failed: …`, invalid repository/organization/interval) stay until you close them.
- **Internal**: notice lifetime lives in `src/client/notice.ts`; every notice gets a fresh incrementing id, so repeating the same text restarts the timer; the suite grew to 111 tests.
